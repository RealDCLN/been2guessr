How to import this into GeoGuessr
  1. Open GeoGuessr and create a new map in the map editor.
  2. Choose Import locations, or use the copy and paste map data userscript.
  3. Upload the JSON file you just downloaded.
  4. If your editor only accepts a bare list, build again with the CLI --array flag.

Every location includes a panoId, so the map uses the exact panorama that was selected. Keep the map unlisted if you only made it for yourself.

What happens under the hood

Three steps and no login. Your map is read from the public GeoJSON behind BeenEverywhere, then every pick is checked against Street View.

  1. 01

    Read your map

    been2guessr pulls the public GeoJSON from BeenEverywhere, the same data behind your visited-cities map. No login, no scraping of your profile page.

  2. 02

    Find real panoramas

    For each place it searches Google Street View coverage, reads panorama metadata, and discards indoor, broken, and duplicate picks.

  3. 03

    Build a balanced map

    Locations are spread across every place you visited, with a minimum distance between picks. Then it writes the GeoGuessr JSON with pano IDs.
